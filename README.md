# LIPSS dashboard — частини сторінки

Тут лежить лише код дашборда: стилі, рантайм, шаблон і логіка розрахунків.

**Даних тут немає.** Цифри читаються з Google-таблиці при кожному відкритті
сторінки, на боці Apps Script. Цей репозиторій потрібен лише для того, щоб
Apps Script міг підтягнути код, не вставляючи його вручну в редактор.
